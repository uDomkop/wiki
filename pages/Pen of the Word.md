# Pen of the Word

```
A Word like a Sword.

A sentence as a Strike.

A strike at thee.

I strike at thee mind.

Between us the word.

The word.

See the word, and see its destruction.

See the word, and see the ideal.

See how you see.

What I see.

See how using the word propels us.

See how it propels it.

And how it stalls.

For as we move,

For we move as 7billion.

But also as A&B

The one that have read this, and the ones who have not.

Word.

```

-DeDomkop
