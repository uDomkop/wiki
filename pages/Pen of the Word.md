# Pen of the Word

```
A Word like a Sword.

A sentence as a Strike.

A strike at thee.

I strike at thee mind.

Between us the word.
```

# The word.
```

See the word, and see its destruction.

See the word, and see the ideal.

See how you see.

What I see.

See how using the word propels us.

See how it propels it.

And how yours stalls.

For as we move,

For [currently only me] move as [one].

The Word moves within thee.

I give you my power.

For I give it to thee.
```
